# Faultless v13.0.0 - Authentication & Authorization

> 年份：2026 | 模拟开发：v12.0.0 完成后，新增认证授权模块

## 核心特性

### JWT 认证 (JsonWebToken)

#### JwtService
```typescript
@Injectable()
export class JwtService {
  constructor(config: JwtConfig);
  sign(payload: UserPayload, options?: SignOptions): string;
  verify<T>(token: string): T;
  decode<T>(token: string): T | null;
  generateTokenPair(payload: UserPayload): JwtToken;
  refreshToken(refreshToken: string): JwtToken;
}
```

#### 配置
```typescript
interface JwtConfig {
  secret: string;
  expiresIn?: string | number;
  issuer?: string;
  audience?: string;
}
```

#### 令牌格式
```typescript
interface JwtToken {
  accessToken: string;
  refreshToken?: string;
  expiresIn: number;
  tokenType: string; // "Bearer"
}
```

### 密码服务 (PasswordService)

#### PasswordService
```typescript
@Injectable()
export class PasswordService {
  constructor(saltRounds?: number);
  hash(password: string): Promise<string>;
  compare(password: string, hash: string): Promise<boolean>;
  generateToken(length?: number): string;
}
```

- 使用 bcryptjs 进行密码哈希
- 默认 10 轮 salt

### 角色服务 (RoleService)

#### RoleService
```typescript
@Injectable()
export class RoleService {
  createRole(name: string, permissions: string[]): void;
  getRole(name: string): Role | undefined;
  getAllRoles(): Role[];
  deleteRole(name: string): boolean;
  hasPermission(roleName: string, permission: string): boolean;
  userHasPermission(userRoles: string[], permission: string): boolean;
}
```

#### 角色定义
```typescript
interface Role {
  name: string;
  permissions: string[];
}
```

### API Key 服务 (ApiKeyService)

#### ApiKeyService
```typescript
@Injectable()
export class ApiKeyService {
  generateApiKey(userId: string, permissions?: string[]): string;
  validateApiKey(key: string): { valid: boolean; userId?: string; permissions?: string[] };
  deleteApiKey(key: string): boolean;
  getUserApiKeys(userId: string): string[];
}
```

- API Key 格式: `nf_` + 48 位随机字符串
- 支持用户关联和权限控制

## 认证中间件

### createAuthMiddleware
```typescript
function createAuthMiddleware(jwtService: JwtService): Middleware;
```

- 验证 `Authorization: Bearer <token>` 头
- 解析用户载荷到 `request.user`
- 返回 401 如果令牌无效或缺失

### createRoleMiddleware
```typescript
function createRoleMiddleware(roleService: RoleService, ...requiredRoles: string[]): Middleware;
```

- 检查用户是否具有指定角色
- 返回 403 如果权限不足

### createPermissionMiddleware
```typescript
function createPermissionMiddleware(roleService: RoleService, permission: string): Middleware;
```

- 检查用户是否具有指定权限
- 返回 403 如果权限不足

### createApiKeyMiddleware
```typescript
function createApiKeyMiddleware(apiKeyService: ApiKeyService): Middleware;
```

- 验证 `X-API-Key` 头
- 返回 401 如果 API Key 无效

## 使用示例

### 注册和登录
```typescript
const authController = new AuthController();

// 注册
const result = await authController.register({
  body: { email: 'user@example.com', password: 'password123' }
});

// 登录
const loginResult = await authController.login({
  body: { email: 'user@example.com', password: 'password123' }
});
// 返回: { accessToken, refreshToken, expiresIn, tokenType }
```

### 路由保护
```typescript
// 需要认证的路由
app.get('/profile', {
  preHandler: [createAuthMiddleware(jwtService)]
}, async (request, reply) => {
  const user = request.user;
  return { user };
});

// 需要特定角色
app.get('/admin', {
  preHandler: [
    createAuthMiddleware(jwtService),
    createRoleMiddleware(roleService, 'admin')
  ]
}, async (request, reply) => {
  return { message: 'Hello Admin!' };
});

// 需要特定权限
app.delete('/posts/:id', {
  preHandler: [
    createAuthMiddleware(jwtService),
    createPermissionMiddleware(roleService, 'posts:delete')
  ]
}, async (request, reply) => {
  return { message: 'Post deleted' };
});
```

### API Key 认证
```typescript
// 生成 API Key
const apiKey = apiKeyService.generateApiKey(userId, ['posts:read']);

// 使用 API Key
app.get('/posts', {
  preHandler: [createApiKeyMiddleware(apiKeyService)]
}, async (request, reply) => {
  const userId = request.userId;
  return { posts: [] };
});
```

## 权限格式

推荐使用 `资源:操作` 格式：
- `users:read` - 读取用户
- `users:write` - 写入用户
- `users:delete` - 删除用户
- `posts:read` - 读取文章
- `posts:write` - 写入文章
- `posts:delete` - 删除文章
- `*` - 所有权限

## 依赖

- `jsonwebtoken` - JWT 签发和验证
- `bcryptjs` - 密码哈希
- `@Faultless/core` - 核心框架

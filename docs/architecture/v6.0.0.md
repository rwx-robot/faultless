## New Features in v6.0.0

### gRPC Server (`grpc-server.ts`)

```typescript
const server = createGrpcServer({
  port: 50051,
  host: '0.0.0.0',
  maxReceiveMessageLength: 4 * 1024 * 1024,
  maxSendMessageLength: 4 * 1024 * 1024,
  keepalive: {
    timeMs: 30000,
    timeoutMs: 5000,
    permitWithoutCalls: true,
  },
  gracefulShutdown: {
    timeoutMs: 30000,
    signals: ['SIGTERM', 'SIGINT'],
  },
});

// Load service from proto file
await server.addServiceFromProto(
  './proto/user.proto',
  'userservice.UserService',
  userServiceImplementation
);

// Start server
await server.start();
```

**Features:**
- Proto file loading with @grpc/proto-loader
- Service registration
- Interceptor chain (auth, logging, metrics)
- Health check service
- Reflection service
- Graceful shutdown with timeout

### gRPC Client (`grpc-client.ts`)

```typescript
const client = createGrpcClient({
  target: 'localhost:50051',
  credentials: grpc.credentials.createInsecure(),
  connectionPool: {
    minConnections: 2,
    maxConnections: 10,
    idleTimeoutMs: 60000,
  },
  retry: {
    maxRetries: 3,
    initialDelayMs: 100,
    maxDelayMs: 5000,
  },
  timeout: {
    defaultMs: 30000,
    perMethod: {
      '/userservice.UserService/GetUser': 5000,
      '/userservice.UserService/CreateUser': 10000,
    },
  },
});

// Unary call
const user = await client.unary('/userservice.UserService/GetUser', { id: '1' });

// Server streaming
const stream = client.serverStream('/userservice.UserService/StreamUsers', { count: 10 });
stream.on('data', (user) => console.log(user));

// Client streaming
const result = await client.clientStream('/userservice.UserService/BulkCreate', users);

// Bidirectional streaming
const bidi = client.bidirectionalStream('/userservice.UserService/Chat');
bidi.send({ message: 'Hello' });
bidi.on('data', (response) => console.log(response));
```

### Proto Loader (`protobuf.ts`)

Helper for proto file operations:

```typescript
const helper = createProtobufHelper();

// Load proto file
await helper.loadFile('./proto/user.proto');

// Or load from string
helper.loadFromString(`
  syntax = "proto3";
  package test;
  message TestMessage {
    string id = 1;
    string name = 2;
  }
`);

// Parse schema
const schema = helper.parseSchema();
console.log(schema.messages); // [User, GetUserRequest, ...]
console.log(schema.services); // [UserService]
console.log(schema.enums);   // [UserStatus]

// Encode/decode
const buffer = helper.encode('test.TestMessage', { id: '1', name: 'test' });
const decoded = helper.decode('test.TestMessage', buffer);

// Create instance
const message = helper.create('test.TestMessage', { id: '1' });

// Verify
const error = helper.verify('test.TestMessage', { id: '1', name: 'test' });
```

### RPC Authentication (`rpc-auth.ts`)

Service-to-service authentication:

```typescript
const auth = createRpcAuth({
  tokenProvider: new JwtTokenProvider({
    token: 'initial-jwt-token',
    refreshToken: 'refresh-token',
    refreshCallback: async (refreshToken) => {
      // Call auth service to refresh
      const result = await authService.refresh(refreshToken);
      return { token: result.token, refreshToken: result.refreshToken };
    },
  }),
});

// Create client interceptor
const interceptor = auth.createClientInterceptor({
  metadataKey: 'authorization',
  excludeMethods: ['/healthcheck'],
});

// Create server middleware
const middleware = auth.createServerMiddleware({
  validateToken: async (token) => {
    // Validate JWT
    return verifyJwt(token);
  },
  excludeMethods: ['/healthcheck'],
});
```

**Token Providers:**
- `SimpleTokenProvider` - Static token or getter function
- `JwtTokenProvider` - JWT with automatic refresh

### Connection Pool (`connection-pool.ts`)

Connection management:

```typescript
const pool = createConnectionPool({
  target: 'localhost:50051',
  minConnections: 2,
  maxConnections: 10,
  idleTimeoutMs: 60000,
  maxLifetimeMs: 300000,
  healthCheck: {
    enabled: true,
    intervalMs: 30000,
    timeoutMs: 5000,
  },
});

// Acquire connection
const { channel, release } = await pool.acquire();
try {
  // Use channel
} finally {
  release();
}

// Get stats
const stats = pool.getStats();
console.log(stats.total, stats.idle, stats.busy);

// Scale pool
await pool.scale(20);
```

**Features:**
- Min/max connection limits
- Idle connection recycling
- Connection health checks
- Lifetime limits
- Pool statistics

### Connection Pool Manager

Manage multiple pools:

```typescript
const manager = connectionPoolManager;

// Get or create pools
const pool1 = manager.getOrCreate('user-service', { target: 'localhost:50051' });
const pool2 = manager.getOrCreate('order-service', { target: 'localhost:50052' });

// Get all stats
const allStats = manager.getAllStats();

// Close all
await manager.closeAll();
```

## Design Decisions

1. **gRPC over Custom RPC** - Industry standard, better tooling
2. **Proto-first Development** - Define API contracts first
3. **Connection Pooling** - Reuse connections for performance
4. **JWT Authentication** - Stateless, scalable
5. **Graceful Shutdown** - Complete in-flight requests
6. **Interceptor Pattern** - Consistent middleware for HTTP and gRPC

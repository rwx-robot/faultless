# Faultless Framework Architecture - v1.0.0 (2015)

## Core Components

### 1. HttpApplication (Entry Point)
- Bootstraps the application
- Loads configuration from multiple sources
- Resolves module dependencies topologically
- Registers controllers, providers, middleware, guards, interceptors, pipes, filters
- Manages application lifecycle

### 2. HttpServer
- Wraps Fastify instance
- Provides unified interface for routes, middleware, error handling
- Handles HTTPS, request/response decorators
- Built-in error handler with structured error responses

### 3. Router
- Registers controllers with prefix
- Resolves route parameters (params, query, body, headers)
- Builds Fastify schemas for validation
- Supports global pipes

### 4. Module System
- `@Module()` decorator for module definition
- Supports imports, controllers, providers, exports
- Topological sorting for dependency resolution
- Global modules support

### 5. Dependency Injection
- Constructor-based injection
- Support for `useClass`, `useValue`, `useFactory`
- Scopes: singleton (default), request, transient
- Circular dependency detection

### 6. Decorators
- `@Controller(prefix)` - Define controller with route prefix
- `@Get()/@Post()/@Put()/@Delete()/@Patch()` - HTTP method decorators
- `@Param()/@Query()/@Body()/@Headers()/@Session()/@Req()/@Res()/@Next()` - Parameter decorators
- `@Inject()` / `@Optional()` - Dependency injection
- `@UseGuards()/@UseInterceptors()/@UsePipes()/@UseFilters()/@UseMiddleware()` - Cross-cutting concerns

## Logging

- Multiple transports: Console, File, Rotating File, HTTP
- Formatters: JSON, Pretty, Simple, Logfmt
- Log levels: fatal, error, warn, info, debug, trace
- Context support and sensitive data redaction
- Child loggers for contextual logging

## Error Handling

Structured error responses:
```json
{
  "error": "ERROR_CODE",
  "message": "Human readable message",
  "details": {},
  "requestId": "req_xxx",
  "timestamp": "2024-01-01T00:00:00.000Z"
```

- `ConflictError` (409)
- `TooManyRequestsError` (429)

## Design Decisions

1. **Fastify as Foundation** - High performance, schema-based validation, hooks system
2. **Decorator-based** - Familiar to NestJS developers, TypeScript-first
3. **Module System** - Encapsulation and dependency management
4. **DI Container** - Inversion of control, testability
5. **Multi-source Config** - Flexible configuration for different environments
6. **Structured Logging** - JSON output for log aggregation
7. **Error Codes** - Machine-readable error handling
8. **Request ID** - Distributed tracing foundation

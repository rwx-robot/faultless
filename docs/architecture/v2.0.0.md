# Faultless Framework Architecture - v2.0.0 (2016)

## Overview

This document describes the architecture of Faultless v2.0.0, focusing on enhanced configuration management and advanced logging capabilities, inspired by modern microservice architecture's configcenter and logx modules.

## New Features in v2.0.0

### Configuration Enhancements

#### 1. Config Encryption (`@Faultless/config/encryption`)
- AES-256-GCM encryption for sensitive configuration
- Password-based key derivation with scrypt
- Automatic IV and salt generation
- Authenticated encryption with integrity verification
- Versioned encrypted payloads

```typescript
import { createEncryption } from '@Faultless/config';

const encryption = createEncryption('master-password');
const encrypted = encryption.encrypt({ password: 'secret', apiKey: 'sk-...' });
const decrypted = encryption.decrypt(encrypted);
```

#### 2. Remote Config Sources (`@Faultless/config/remote`)
- **etcd3** integration with watch support
- **Consul** KV store integration
- **Custom** provider interface for other systems (Nacos, Apollo, etc.)
- Automatic reconnection and watch management
- Prefix-based key mapping to nested config objects

```typescript
import { createRemoteConfigSource } from '@Faultless/config';

const etcdSource = createRemoteConfigSource(
  'etcd-config',
  50,
  { type: 'etcd', endpoints: ['localhost:2379'], namespace: 'myapp' },
  '/config/'
);
```

#### 3. Config Versioning (`@Faultless/config/versioning`)
- Immutable version history with metadata
- Rollback support with automatic version creation
- Diff computation between versions
- Configurable retention with auto-cleanup
- Multiple storage backends (Memory, File, extensible)

```typescript
import { ConfigVersionManager, MemoryVersionStorage } from '@Faultless/config';

const versionManager = new ConfigVersionManager({
  storage: new MemoryVersionStorage(),
  maxVersions: 50,
  autoCleanup: true,
});

await versionManager.createVersion(config, 'admin', 'Updated database config');
const rolledBack = await versionManager.rollback(3);
const diff = await versionManager.diff(1, 5);
```

### Logging Enhancements

#### 1. Structured Logging (`@Faultless/log/structured`)
- Automatic field extraction from metadata
- OpenTelemetry-compatible trace/span IDs
- Service name, environment, version enrichment
- Custom field extractors

```typescript
const logger = createLogger({
  structuredFields: true,
  serviceName: 'my-service',
  environment: 'production',
  version: '2.0.0',
});

logger.info('Request processed', 'HttpServer', { duration: 150, status: 200 });
// Output includes: fields, traceId, serviceName, environment, version
```

#### 2. Log Sampling (`@Faultless/log/structured`)
- **AlwaysSampler** - Log everything
- **NeverSampler** - Log nothing
- **ProbabilisticSampler** - Random percentage
- **LevelBasedSampler** - Different rates per level
- **RateLimitedSampler** - Max logs per second
- **CompositeSampler** - Combine multiple samplers

```typescript
const logger = createLogger({
  sampler: 'level', // Uses LevelBasedSampler defaults
  samplerOptions: { rate: 0.1 }, // For probabilistic
});
```

#### 3. Async Writers (`@Faultless/log/structured`)
- **BufferedAsyncWriter** - Batch writes for any transport
- **BatchedHttpWriter** - Optimized HTTP batching
- Configurable buffer size and flush interval
- Automatic flush on buffer full or interval

```typescript
const logger = createLogger({
  asyncWrite: true,
  asyncWriteOptions: { bufferSize: 100, flushInterval: 1000 },
});
```

#### 4. Log Aggregation (`@Faultless/log/structured`)
- **InMemoryLogAggregator** - Query interface for testing/debugging
- Filter by level, context, time range, trace ID, service
- Pagination support
- Extensible interface for external systems (Elasticsearch, Loki, etc.)

```typescript
const logger = createLogger({ ... });
const aggregator = logger.getAggregator();

const errors = await aggregator.query({ level: 'error', limit: 50 });
const traceLogs = await aggregator.query({ traceId: 'abc-123' });
```

## Design Decisions

1. **Encryption at Rest** - Config encryption protects secrets in config files
2. **Remote Config** - Dynamic configuration without restarts (etcd/Consul)
3. **Versioning** - Audit trail and safe rollback for configuration changes
4. **Structured Logging** - Machine-parseable logs for observability platforms
5. **Sampling** - Control log volume in high-throughput services
6. **Async Writing** - Non-blocking logging for performance
7. **Aggregation Interface** - Unified query interface for log analysis
